Reading a Remote Teammate’s Body

This project investigates how remote collaboration can feel more embodied and communicative when digital systems help teammates interpret one another’s attention, stress, and presence. In distributed work settings, body language is often lost or flattened into text, icons, and video tiles. This project explores how designers can create interfaces that surface subtle social signals without becoming intrusive or overly explicit.

The work focuses on the relationship between digital presence and physical awareness. Rather than simply displaying static status indicators, the system tries to synthesize cues such as engagement, workload, and conversational readiness into a shared interface that teammates can read quickly during collaboration. The aim is not to replace human communication but to support it by making the invisible qualities of a remote interaction more legible.

Through a combination of interface design, interaction mapping, and behavioral research, the project explores how information about the body can be translated into useful collaborative signals. It reflects a broader interest in tools that allow people to sense one another’s state across distance—especially in situations where attention and emotional regulation strongly influence group performance and coordination.

Tech: Interface prototyping, collaborative UX systems, interaction design, remote communication research.

Role: Research, UX Design, Interaction Systems, Team Collaboration Design.
